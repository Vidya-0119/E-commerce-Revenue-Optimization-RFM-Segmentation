# Customer Segmentation & Behavioral Persona Modeling

This project builds an end‑to‑end customer segmentation pipeline using real-world e‑commerce transactional data. The goal is to identify meaningful behavioral personas that can support CRM strategy, lifecycle automation, and targeted marketing.

---

## 🔍 Project Overview

I engineered behavioral features such as:
- Total spend
- Total orders
- Average purchase gap days
- Unique product categories explored

Using these features, I applied clustering techniques to uncover distinct customer personas and validated them through multiple visualizations.

---

## 🧠 Key Insights

### **1. Behavioral Fingerprints (Heatmap)**
A normalized heatmap highlights four distinct personas:
- **High‑Value Loyalists**
- **At‑Risk Minimalists**
- **Focused Steady Buyers**
- **Occasional Big Basket Shoppers**

### **2. Category Affinity (Bar Chart)**
Each segment shows unique product category preferences, confirming the behavioral differences observed in the heatmap.

### **3. Spend vs Frequency (Scatter Plot)**
The scatter plot validates the segmentation by showing clear separation in spending and ordering patterns.
